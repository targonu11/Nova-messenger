----------------------------------------
  Ошибка PowerShell: npm.ps1 отключён
----------------------------------------

В PowerShell вместо npm пишите npm.cmd:

   npm.cmd install
   npm.cmd start

Или один раз (разрешить скрипты только для вашего пользователя):

   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Либо откройте cmd (не PowerShell) или запускайте .bat файлы двойным щелчком.
