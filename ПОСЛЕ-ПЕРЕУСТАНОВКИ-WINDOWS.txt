Nova Messenger — как продолжить работу после переустановки Windows
================================================================

Проект сохранён на GitHub:
https://github.com/targonu11/Nova-messenger

Весь код (269 файлов), история коммитов и ветка main — там.


ЧТО СОХРАНИТСЯ
--------------

На GitHub (100%):
  - Весь код проекта
  - История коммитов
  - Ветка main

После переустановки Windows нужно установить заново:
  - Git
  - Node.js
  - Cursor


КАК ПРОДОЛЖИТЬ РАБОТУ
---------------------

1. Установи Git, Node.js и Cursor.

2. Войди в Cursor под тем же аккаунтом (если был).

3. Склонируй репозиторий:

   git clone https://github.com/targonu11/Nova-messenger.git
   cd Nova-messenger

4. Открой эту папку в Cursor (File → Open Folder).

5. Установи зависимости:

   npm install
   cd client
   npm install
   cd ../server
   npm install

6. Запусти проект (если нужно):

   start-nova.bat

7. Пиши в чат Cursor — «добавь X», «исправь Y» — и работа продолжается.


ПРО ЧАТ С CURSOR
----------------

  - Код не потеряется — он на GitHub.
  - История чата может не полностью сохраниться после переустановки Windows.
    Это не критично: открой проект, кратко опиши что это Nova Messenger и что
    нужно сделать — и продолжай работу.
  - Настройки Cursor частично подтянутся, если войти в тот же аккаунт.


ПЕРЕД ПЕРЕУСТАНОВКОЙ WINDOWS (рекомендуется)
----------------------------------------------

1. Запушь все изменения на GitHub:

   git add .
   git commit -m "описание изменений"
   git push

2. Сохрани ссылку на репозиторий:
   https://github.com/targonu11/Nova-messenger

3. Если есть файл .env с паролями и ключами — сохрани его отдельно
   (он не попадает в git, это нормально).

4. Если есть локальные базы данных (*.db) — сохрани их отдельно, если нужны.


ЧТО НЕ В GIT (и это нормально)
------------------------------

Следующие файлы и папки не хранятся в репозитории (.gitignore):

  - node_modules/     — ставится через npm install
  - .env              — секреты и ключи
  - dist/, build/     — сборки
  - *.db              — базы данных
  - логи

На новом ПК их нужно создать или установить заново.


ИТОГ
----

Переустановил Windows → склонировал репо → открыл в Cursor → npm install → работаешь дальше.
