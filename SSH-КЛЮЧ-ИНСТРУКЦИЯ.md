# Как создать и использовать SSH ключ для Яндекс.Облака

SSH ключ нужен, чтобы подключаться к виртуальной машине без пароля. На Windows его можно создать в PowerShell.

---

## Шаг 1. Создать SSH ключ на компьютере

1. Откройте **PowerShell** (правый клик по кнопке «Пуск» → **Windows PowerShell** или **Терминал**).

2. Выполните команду (можно оставить email своим или любым):

```powershell
ssh-keygen -t ed25519 -C "nova-yandex-cloud"
```

3. Программа спросит, **где сохранить ключ**. По умолчанию предлагается:
   ```
   C:\Users\ВашеИмя\.ssh\id_ed25519
   ```
   Просто нажмите **Enter**, чтобы использовать это место.

4. Спросят **парольную фразу (passphrase)**. Можно:
   - нажать **Enter** два раза — пароля не будет (удобно для автоматического доступа);
   - либо ввести пароль — тогда при каждом подключении его нужно будет вводить (безопаснее).

5. После этого появятся сообщения вроде:
   ```
   Your identification has been saved in C:\Users\ВашеИмя\.ssh\id_ed25519
   Your public key has been saved in C:\Users\ВашеИмя\.ssh\id_ed25519.pub
   ```
   Значит ключ создан.

---

## Шаг 2. Скопировать публичный ключ

Публичный ключ — это содержимое файла с расширением **.pub**. Его нужно будет вставить в Яндекс.Облако.

В PowerShell выполните:

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
```

Или, если создавали ключ с именем по умолчанию (rsa):

```powershell
Get-Content $env:USERPROFILE\.ssh\id_rsa.pub
```

Скопируйте **всю строку** из вывода (начинается с `ssh-ed25519` или `ssh-rsa`, заканчивается вашим email или комментарием). Пробелы в начале и конце не нужны.

**Вариант через блокнот:** откройте файл в Блокноте и скопируйте одну строку:
- Файл: `C:\Users\ВашеИмя\.ssh\id_ed25519.pub`

---

## Шаг 3. Добавить ключ в Яндекс.Облако

### Если виртуальная машина ещё не создана

При создании VM в разделе **Доступ**:

1. **Метод доступа:** выберите «SSH-ключ».
2. Нажмите **«Добавить ключ»**.
3. Вставьте скопированную строку публичного ключа в поле.
4. Сохраните и создайте VM.

### Если виртуальная машина уже создана

1. Зайдите в https://console.cloud.yandex.ru/
2. **Compute Cloud** → **Виртуальные машины** → выберите вашу VM.
3. Нажмите **«Подключиться»** (или откройте вкладку с информацией о подключении).
4. Там может быть раздел про добавление ключа в **метаданные** VM.

Либо добавьте ключ через **метаданные** каталога/VM:

1. **Compute Cloud** → **Виртуальные машины** → ваша VM.
2. Вкладка **Обзор** или **Дополнительно** → блок про SSH-ключи / метаданные.
3. Добавьте ключ в метаданные с ключом `ssh-keys` в формате:
   ```
   ubuntu:ssh-ed25519 AAAAC3...ваш_ключ... nova-yandex-cloud
   ```
   (логин `ubuntu`, пробел, затем вся строка из `.pub` файла).

Точное название полей в консоли может отличаться — ищите раздел «Доступ», «SSH-ключи» или «Метаданные».

---

## Шаг 4. Подключиться к VM

В PowerShell выполните (подставьте свой IP):

```powershell
ssh ubuntu@ваш-ip-адрес
```

Например:

```powershell
ssh ubuntu@158.160.12.34
```

При первом подключении спросят:
```
Are you sure you want to continue connecting (yes/no)?
```
Введите **yes** и нажмите Enter.

Если ключ добавлен в облако и путь к ключу стандартный (`C:\Users\ВашеИмя\.ssh\id_ed25519` или `id_rsa`), Windows и OpenSSH подставят его автоматически.

---

## Если ключ сохраняли в другой файл

Подключение с указанием ключа:

```powershell
ssh -i C:\Users\ВашеИмя\.ssh\имя_файла_ключа ubuntu@ваш-ip-адрес
```

Например:

```powershell
ssh -i C:\Users\roman\.ssh\id_ed25519 ubuntu@158.160.12.34
```

---

## Кратко

| Действие | Команда / место |
|----------|------------------|
| Создать ключ | `ssh-keygen -t ed25519 -C "nova-yandex-cloud"` в PowerShell |
| Публичный ключ | Содержимое файла `C:\Users\ВашеИмя\.ssh\id_ed25519.pub` |
| Показать ключ | `Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub` |
| Куда вставить | Консоль Яндекс.Облака → создание VM или метаданные VM → SSH-ключ |
| Подключение | `ssh ubuntu@ваш-ip` |

**Важно:** в облако добавляется только **публичный** ключ (файл `.pub`). Файл **без** расширения `.pub` (приватный ключ) никому не передавайте и никуда не вставляйте.
