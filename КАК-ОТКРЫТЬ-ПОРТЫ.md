# Как открыть порты на виртуальной машине в Яндекс.Облаке

Порты открываются в **группе безопасности** (Security group), привязанной к сети VM.

---

## Если VM ещё не создана

При создании виртуальной машины в разделе **Сетевые настройки**:

1. Нажмите **«Создать новую»** в блоке группы безопасности.
2. Укажите имя, например: `nova-security-group`.
3. В блоке **Правила** → **Входящий трафик** нажмите **«Добавить правило»** и добавьте строки:

| Направление | Протокол | Порт    | Источник    | Описание |
|-------------|----------|---------|-------------|----------|
| Входящий    | TCP      | 22      | 0.0.0.0/0   | SSH      |
| Входящий    | TCP      | 80      | 0.0.0.0/0   | HTTP     |
| Входящий    | TCP      | 443     | 0.0.0.0/0   | HTTPS    |

4. Сохраните группу и продолжите создание VM.

---

## Если VM уже создана

### Шаг 1. Открыть консоль и перейти к группам безопасности

1. Зайдите на https://console.cloud.yandex.ru/
2. Выберите нужный каталог.
3. В меню слева: **VPC** → **Группы безопасности**  
   (или **Сеть** → **Группы безопасности** в зависимости от интерфейса).

### Шаг 2. Найти группу, привязанную к вашей VM

- В списке найдите группу, которая указана у вашей виртуальной машины (в карточке VM смотрите блок «Сеть» / «Группы безопасности»).
- Если у VM группа **default** — откройте именно её.
- Нажмите на название группы.

### Шаг 3. Добавить правила входящего трафика

1. Перейдите на вкладку **Правила** (или **Rules**).
2. В блоке **Входящий трафик** (Inbound) нажмите **«Добавить правило»** / **Add rule**.
3. Добавьте по одному правилу на порт:

**Порт 22 (SSH):**
- Протокол: **TCP**
- Порт: **22** (или диапазон 22–22)
- Источник: **CIDR** → `0.0.0.0/0` (доступ с любого IP)
- Описание (необязательно): `SSH`

**Порт 80 (HTTP):**
- Протокол: **TCP**
- Порт: **80**
- Источник: **CIDR** → `0.0.0.0/0`
- Описание: `HTTP`

**Порт 443 (HTTPS):**
- Протокол: **TCP**
- Порт: **443**
- Источник: **CIDR** → `0.0.0.0/0`
- Описание: `HTTPS`

4. Нажмите **«Сохранить»** / **Save**.

### Шаг 4. Проверить привязку группы к VM

- Перейдите в **Compute Cloud** → **Виртуальные машины**.
- Откройте вашу VM.
- В блоке **Сеть** должна быть указана та же группа безопасности, в которой вы добавили правила.

Если у VM не было группы — при создании VM или при изменении сетевого интерфейса нужно выбрать созданную группу (например, `nova-security-group`).

---

## Кратко

| Что сделать | Где |
|-------------|-----|
| Открыть порты | **VPC** → **Группы безопасности** → нужная группа |
| Добавить правило | В группе → **Правила** → **Входящий трафик** → **Добавить правило** |
| Указать порт | Протокол TCP, порт 80 (или 22, 443) |
| Разрешить всем | Источник: `0.0.0.0/0` |

После сохранения правил порты начинают работать без перезагрузки VM.
